# Canal infantil — producción de videos con agentes

1. Lee `REQUISITOS.md` (herramientas gratuitas, cuentas, licencias, checklist).
2. Cierra `biblia-de-personajes.md`.
3. Para cada video crea `canal-infantil/videos/<slug>/` y pide a los agentes, en orden:
   `guionista-infantil` → `director-de-prompts` → `generador-de-video` → `ensamblador-local` (herramienta `herramientas/producir.py`) → `publicador-youtube`. `editor-audio-subtitulos` es la alternativa manual (DaVinci/CapCut).

Ejemplo ya producido: `../video-infantil/subtitulos.srt` (video de 6 min con patitos, colores, autobús, monitos, tren y globos).
