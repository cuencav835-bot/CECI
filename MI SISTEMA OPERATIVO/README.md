# MI SISTEMA OPERATIVO

Este es tu sistema operativo de trabajo: el lugar donde vive todo tu contexto, tus proyectos y tus plantillas reutilizables, para que cualquier trabajo que hagamos parta de la misma base.

```
MI SISTEMA OPERATIVO/
  CONTEXTO/    → quién eres, tu negocio, tu cliente ideal, tu estilo, tus prioridades
  PROYECTOS/   → cada proyecto concreto en el que trabajas
  SKILL/       → plantillas y procesos reutilizables
```

Empieza por `CONTEXTO/` — ahí se guarda la información base que se usa en todo lo demás.
