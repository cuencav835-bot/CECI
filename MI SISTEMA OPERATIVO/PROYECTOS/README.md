# PROYECTOS

Aquí va cada proyecto o negocio concreto en el que trabajas: un guion de YouTube, una campaña de Instagram, un curso digital, una landing page, etc.

Cada proyecto debería vivir en su propia subcarpeta, por ejemplo:

```
PROYECTOS/
  youtube-mas-salud/
  pizza-hut-instagram/
  reto-quema-grasa-7-dias/
  seo-hotmart/
```

Antes de trabajar en un proyecto nuevo, revisa `CONTEXTO/` para mantener consistencia con tu marca, tu cliente ideal y tu estilo de comunicación.
