# CONTEXTO

Aquí vive toda la información sobre ti y tus negocios: quién eres, qué vendes, quién es tu cliente ideal, tu estilo de comunicación y tus prioridades actuales.

Este contexto se usa como base para todo lo que se genere en `PROYECTOS/` (guiones, contenido, copys, estrategias, etc.), para que cada pieza sea consistente con tu marca y tu forma de comunicar.

## Archivos

- `perfil.md` — quién eres, tus negocios/proyectos activos.
- `cliente-ideal.md` — a quién le vendes en cada negocio/proyecto.
- `estilo-comunicacion.md` — tono, voz, referencias visuales.
- `prioridades.md` — en qué estás enfocado ahora mismo.

Se actualiza según cambien tus respuestas — nunca se inventa información aquí.
